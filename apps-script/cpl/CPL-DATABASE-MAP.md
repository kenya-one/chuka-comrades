# CPL database map

| Sheet | Purpose |
|---|---|
| Settings | System rules such as points and referee fee |
| Users | Firebase users and CPL role state |
| Seasons | CPL seasons |
| TransferWindows | Pre-season/mid-season transfer periods |
| Teams | League A/B teams and coach/captain |
| Players | Approved season squad records |
| PlayerApplications | Player requests awaiting review |
| Follows | Fan/team follows |
| Fixtures | League and Cup matches |
| MatchPosters | Coach-uploaded fixture posters |
| Lineups | Coach lineups and late flags |
| MatchReports | Referee results awaiting/after Chairman approval |
| MatchEvents | Normalized match events |
| Transfers | Four-step player transfer workflow |
| TransferLog | Every transfer state change |
| Competitions | CPL Cup and future competitions |
| CompetitionTeams | Teams entered into a competition |
| CompetitionRounds | Cup rounds |
| CompetitionFixtures | Cup bracket links |
| TeamCollections | Team fundraising/collections |
| CollectionPayments | Individual collection payments |
| WhatsAppGroups | Team/community/official group links |
| News | CPL announcements |
| DriveFiles | Drive file registry |
| Disputes | Match disputes and Chairman decisions |
| AuditLog | Append-only audit chain |
| DeletionReceipts | Proof that a collection was Chairman-approved before deletion |
